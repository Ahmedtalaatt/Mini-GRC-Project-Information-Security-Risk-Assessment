# Mini GRC Project: NileTech Payments (fictional company)

An information security risk assessment for a fictional 250-person Egyptian payments company, built as an entry-level GRC portfolio project by **Ahmed Talaat**.

## What's inside
| File | Contents |
|---|---|
| `NileTech_GRC_Portfolio.pdf` | Key assets, 5×5 risk method and appetite, risk register overview with heat maps, ISO 27001 control mapping, Access Control Policy, executive summary, audit finding |
| `NileTech_Risk_Register.xlsx` | Full register: 10 risks (Cause → Event → Consequence), scores calculated by formula, treatment, owner, due date, ISO/IEC 27001:2022 Annex A mapping, heat maps, scales, asset list |

## Highlights
- 17 assets, 10 risks. Current controls lower the average score from 17.4 to 11.9; 8 risks are still too high.
- Biggest finding: the outsourced developers had a shared, permanent admin account on the cloud servers (R5, rescored 10 → 20 after an access review).
- Frameworks used: ISO/IEC 27001:2022 Annex A, PCI DSS v4.0.1, Egypt data protection law.

*All company names, figures and findings are fictional.*
